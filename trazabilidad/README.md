# Trazabilidad del Subdocumento 2

`Cambios-Subdocumento2.tex` documenta los trece puntos acordados, los cambios realizados, sus fuentes y las dependencias con el Subdocumento 3. Incluye la tabla por punto solicitada.

`verificacion.tex` contiene los resultados de comprobación técnica y se incorpora al informe. `cambios-contenido.patch` conserva el cambio textual exacto respecto de `6adcf15e`.

Para compilar desde esta carpeta:

```powershell
latexmk -lualatex -interaction=nonstopmode -halt-on-error Cambios-Subdocumento2.tex
```

Las fuentes editables de las cuatro figuras intervenidas están en `../figuras/fuentes`. Alex Aravena continúa como responsable de revisión humana. La comprobación técnica no sustituye la validación final de esta edición por el equipo.
