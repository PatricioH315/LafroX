# Subdocumento 13 — Innovaciones

Formulario T-7 (Bases Administrativas). Debe cubrir:

- Cartera obligatoria de **cinco** innovaciones, una por cada tipo del Artículo 28°, en el Formulario T-19.
- Cada innovación con los siete elementos del Artículo 29°: problema, tecnología, madurez, diseño de incorporación, impacto económico, indicador de verificación y riesgo de adopción.
- Trazabilidad de cada innovación con la arquitectura, la EDT y el flujo de caja.
- Fuentes citadas en APA 7.ª edición para innovaciones de base tecnológica.
